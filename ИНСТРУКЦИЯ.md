# PostCraft — как пользоваться

Короткая инструкция для клиента и для себя.

## Как открыть

1. Откройте файл **`index.html`** в браузере (двойной клик или «Открыть с помощью» → Chrome, Edge, Firefox и т.д.).
2. Интернет для работы **не нужен** — всё считается на вашем компьютере.

## Тема оформления (светлая / тёмная)

- Нажмите **«Тёмная тема»** или **«Светлая тема»** — подпись показывает, что **включится** после клика.
- Кнопки есть **в шапке**, **рядом с заголовком «Генератор постов»** и **внизу страницы** (футер).
- Выбор **сохраняется** в браузере: при следующем открытии файла тема останется прежней.

## Быстрый старт без заполнения всего вручную

1. **Примеры ниш** — блок «Примеры ниш» или строка «Быстрый выбор ниши» внутри генератора: нажмите нишу → форма заполнится примером (ниша, продукт, аудитория, цель и т.д.), **тип поста** и **тон** подставятся сами.
2. **Быстрый старт** — три кнопки: эксперт / магазин / услуги — загружают готовый пример под сценарий.
3. **Вставить пример** — в блоке кнопок генератора подставляет демо-текст в поля (косметология / экспертный тон).

Дальше можно править любые поля под свой проект.

## Поля формы (что за что)

| Поле | Зачем |
|------|--------|
| **Ниша** | Сфера (бьюти, обучение, магазин…). |
| **Что продаём / продвигаем** | Продукт, услуга, оффер. |
| **Целевая аудитория** | Кто читает, чем живёт. |
| **Платформа** | Instagram, Telegram, VK или универсально — подстроится подсказка в результате. |
| **Тип поста** | Выбор **из списка** (ничего писать не нужно): продающий, экспертный, кейс, анонс и т.д. |
| **Тон текста** | Мягкий, экспертный, премиальный и др. |
| **Цель поста** | Заявки, прогрев, знакомство с брендом… Можно нажать **быстрые цели** над формой. |
| **УТП, боли, CTA, ключевые слова** | Чем сильнее заполните, тем точнее черновик. |
| **Желаемый объём / формат** | Короткий, длинный, список, история и т.д. |
| **Дополнительные пожелания** | Любые уточнения (без штампов, проще языком…). |
| **Чекбоксы и переключатели** | Эмодзи, «человечнее», сильный оффер и т.п. |

**Быстрые структуры** (AIDA, PAS, проблема → решение…) задают порядок смысловых блоков в тексте.

## Генерация и результат

1. Нажмите **«Сгенерировать пост»**.
2. Ниже появится блок с **вкладками**: основной текст, варианты 2–3, без эмодзи, премиальный, короткий, сторис, хэштеги. На первой вкладке — заголовок, текст, плюс дополнительные блоки (заголовки, входы, CTA, идеи для Reels и т.д.).
3. Объём основного текста обычно **около 1000–1500 символов** — это черновик для доработки «своим голосом».

## Кнопки под формой

- **Очистить форму** — сброс полей и скрытие результата.
- **Вставить пример** — демо-данные в поля.
- **Скопировать текст** — основной заголовок + основной текст в буфер.
- **Скопировать все варианты** — полный пакет в буфер (JSON).
- **Скачать .txt / .json** — сохранить файл.
- **Ещё 2 варианта** — пересобрать второй и третий варианты.
- **Короче / Длиннее**, **Дороже / Мягче / Живее** — правки к уже сгенерированному основному тексту.
- **Создать заново** — полная новая генерация с теми же полями.

## Навигация по странице

- **«Сгенерировать пост»** в первом экране и **«Открыть генератор»** внизу ведут к блоку генератора.
- **«Наверх»** — в футере.
- Для клавиатуры: в начале страницы есть скрытая ссылка **«Перейти к генератору»** (появляется при фокусе Tab).

## Важно понимать

- Это **шаблонный генератор** в браузере, не нейросеть: текст нужно **прочитать и при желании подправить** под бренд и правила площадки.
- Данные формы и последний результат **сохраняются локально** (в этом браузере). В другом браузере или на другом ПК настроек не будет.
- Чтобы **изменить цвета, шаблоны фраз или список ниш**, правятся комментарии и код внутри **`index.html`** (см. подсказки в начале файла в комментарии и в блоке `<style>` / `<script>`).
